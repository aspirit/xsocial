# MongoDB Code Generator

A comprehensive tool to automatically generate type-safe MongoDB-related code by scanning Go source files.

## Purpose

This generator automatically discovers all struct definitions in `internal/model/` and creates:
1. **Field constants** - Type-safe field names for BSON queries
2. **Collection constants** - Compile-time safe collection names
3. **Collection mappings** - Type-to-collection name resolution

## Features

- **🔍 Automatic Discovery**: Scans `internal/model/` directory for all Go files
- **📁 Dynamic Detection**: Finds all exported struct types automatically
- **🏷️ Smart Tag Parsing**: Extracts BSON tags from struct field definitions
- **🗂️ Collection Generation**: Creates collection name constants and mappings
- **🚀 Zero Configuration**: No need to manually enumerate models
- **📝 English Comments**: Generates clean, professional documentation
- **🎨 External Templates**: Uses separate template files for easy customization

## Usage

### Recommended: Using Taskfile (from project root)

```bash
# From anywhere in the project
task gen:mongo
```

This is the recommended way as it:
- Can be run from any directory in the project
- Includes dependency tracking (only regenerates when source files change)
- Integrates with the project's build system
- Provides consistent interface with other project tasks

### Alternative: Direct execution

```bash
# From project root
go run tools/mongo-codegen/generator.go

# Or from tools/mongo-codegen directory
cd tools/mongo-codegen
go run generator.go
```

The generator will:
1. Scan all `.go` files in `internal/model/`
2. Parse AST to find exported struct types
3. Extract field names and BSON tags
4. Load templates from `field.template` and `collection.template`
5. Generate field constants in `internal/storage/mongo/field/`
6. Generate collection constants in `internal/storage/mongo/collections.go`

## Generated Output

### 1. Field Constants

For each model in `internal/model/`, the generator creates a corresponding field definition file in `internal/storage/mongo/field/`.

**Example Input**:
```go
type Account struct {
    ID       uint64 `bson:"_id" json:"id"`
    Email    string `bson:"email" json:"email"`
    Username string `bson:"username" json:"username"`
    // ...
}
```

**Generated Output** (`internal/storage/mongo/field/account.go`):
```go
// Code generated by tools/mongo-codegen. DO NOT EDIT.

package field

// Account field definitions - provides type-safe field name constants
// This helps avoid string literals in BSON queries
var Account = struct {
    ID       string
    Email    string
    Username string
    // ...
}{
    ID:       "_id",
    Email:    "email", 
    Username: "username",
    // ...
}
```

### 2. Collection Constants

The generator creates a single file with all collection constants and mappings.

**Generated Output** (`internal/storage/mongo/collections.go`):
```go
// Code generated by tools/mongo-codegen. DO NOT EDIT.

package mongo

// MongoDB collection name constants
const (
    ACCOUNT = "account"
    USER_INFO = "user_info"
    POST = "post"
    // ... for all models
)

// ModelCollections maps model type names to their collection names
var ModelCollections = map[string]string{
    "Account": ACCOUNT,
    "UserInfo": USER_INFO,
    "Post": POST,
    // ... for all models
}

// GetCollectionName returns the collection name for a given model type name
func GetCollectionName(typeName string) string {
    if collection, exists := ModelCollections[typeName]; exists {
        return collection
    }
    return toSnakeCase(typeName)
}
```

## Template Customization

The generator uses external template files which you can customize without recompiling:

### Field Template (`field.template`)
```go
// Code generated by tools/mongo-codegen. DO NOT EDIT.

package field

// {{ .ModelName }} field definitions - provides type-safe field name constants
var {{ .ModelName }} = struct {
{{- range .Fields }}
	{{ .Name }} string
{{- end }}
}{
{{- range .Fields }}
	{{ .Name }}: "{{ .BsonTag }}",
{{- end }}
}
```

### Collection Template (`collection.template`)
```go
// Code generated by tools/mongo-codegen. DO NOT EDIT.

package mongo

const (
{{- range .Models }}
	{{ .ConstantName }} = "{{ .CollectionName }}"
{{- end }}
)

var ModelCollections = map[string]string{
{{- range .Models }}
	"{{ .ModelName }}": {{ .ConstantName }},
{{- end }}
}
```

## Usage in Code

### Field Constants
Instead of error-prone string literals:
```go
// ❌ Error-prone
filter := bson.M{"email": email}
```

Use type-safe field constants:
```go
// ✅ Type-safe
filter := bson.M{field.Account.Email: email}
```

### Collection Constants
Instead of hardcoded collection names:
```go
// ❌ Hardcoded
collection := db.Collection("account")
```

Use generated constants:
```go
// ✅ Type-safe
collection := db.Collection(mongo.ACCOUNT)

// Or with dynamic resolution
collection := db.Collection(mongo.GetCollectionName("Account"))
```

## How It Works

1. **AST Parsing**: Uses Go's `go/ast` package to parse source files
2. **Struct Detection**: Finds all exported struct type declarations
3. **Field Extraction**: Analyzes struct fields and their BSON tags
4. **Template Loading**: Reads external template files
5. **Code Generation**: Uses Go's `text/template` for code generation
6. **Automatic Formatting**: Applies `go fmt` to ensure clean output

## Adding New Models

Simply create a new struct in `internal/model/` and run the generator:

```go
// internal/model/new_model.go
type NewModel struct {
    ID   uint64 `bson:"_id"`
    Name string `bson:"name"`
}
```

```bash
cd tools/mongo-codegen && go run generator.go
```

The generator will automatically:
- Create `field/new_model.go` with field constants
- Add `NEW_MODEL` constant to `collections.go`
- Update the `ModelCollections` mapping
